# 网文维权助手 - 离线安装包中心

本仓库为《网文维权助手》的 **Chrome 离线安装包** 发布页。由于 Chrome 商店暂未上架，使用 Chrome 浏览器的用户请通过以下步骤手动安装。

> **如果你使用的是 Edge 浏览器**：
> 强烈建议直接前往 [Microsoft Edge 扩展商店](https://microsoftedge.microsoft.com/addons/detail/chfgebleelcbdnahedlmfbndcdbofkfh) 一键安装，可享受自动更新且无需折腾。

---

## 如何下载

1. 点击右侧（或上方）的 **Releases** 标签。
2. 找到最新版本（如 `v1.0.1`），在 `Assets` 下方点击下载 `.zip` 格式的压缩包。
3. *(国内下载慢的话，请前往爱发电主页获取蓝奏云备用下载链接)*。

---

## 如何安装（必看）

1. **解压**：下载后，一定要先将 `.zip` 文件**解压**到一个固定的文件夹（比如 `D:\网文维权助手`）。**千万不要直接在压缩包里运行，也不要随便移动文件夹的位置。**
2. **打开扩展页**：打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并回车。
3. **开启开发者模式**：在页面右上角，把【开发者模式】的开关打开。
4. **加载扩展**：点击左上角的【加载已解压的扩展程序】，选中你刚才解压出来的那个文件夹。
5. 安装完成！点击浏览器右上角的拼图图标，把插件固定出来即可使用。

---

## 重要提示（防丢数据）

手动安装的插件，浏览器有时会在重启后弹窗提示“请停用开发者模式扩展”，甚至把插件置灰。

- **千万不要点“移除”！千万不要卸载！**
- **正确做法**：去 `chrome://extensions/` 页面，把插件右下角的开关重新打开即可。你的所有数据全都在。

建议你定期在插件内使用【导出数据】功能，备份你的链接和白名单。
